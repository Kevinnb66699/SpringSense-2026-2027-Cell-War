# 游戏流程（总览）

游戏以 **[[世界回合]]** 为最高优先级框架组织：

```
世界回合（所有玩家各行动 1 次 = 1 轮）
 ├─ 阶段推进：[[游戏阶段]]（前期 1-10 回合 / 后期 11-20 回合）
 ├─ 玩家回合（每位玩家按[[玩家行动顺序]]依次进行）
 │   ├─ [[玩家回合-判定阶段]]：复活 → 血管 → 抽卡 → 墙壁
 │   ├─ [[玩家回合-行动阶段]]：自由抽卡 → 移动与攻击 → 特殊行动
 │   └─ [[回合结束-回复判定]]：生物质工厂回复
 └─ 世界事件 / 卡池激活节点（由[[游戏阶段]] 决定）
```

## 流程要点

1. **回合推进**：一个[[世界回合]] = 所有玩家各完成一次[[玩家回合]]。
2. **阶段划分**：前 10 回合为**前期**，后 10 回合为**后期**；节奏不同，见 [[游戏阶段]]。
3. **进化节点**：第 10 回合开始时发生[[进化]]。
4. **胜负判定**：20 回合结束时或癌细胞全灭时判定，见 [[胜负条件]]。
