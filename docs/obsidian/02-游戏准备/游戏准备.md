# 游戏准备（组件清单）

开箱后应包含以下组件（ver.0.98）：

| 组件 | 数量 | 说明 |
|------|------|------|
| [[游戏板]] | 1 张 | 由 61 块组织构成的棋盘 |
| [[组织]] | 61 块 | 棋盘上的位置/地块 |
| 游戏手册 | 1 本 | 即本文档来源 |
| [[特殊事件地块]] | 8 张 | 卡池×4、[[血管]]×2、[[生物质工厂]]×1、[[墙壁工厂]]×1 |
| [[棋子]] | 6 枚 | 3 红 + 3 蓝（红=免疫细胞，蓝=癌细胞） |
| [[骰子]] | 2 个 | 用于移动、攻击、抽卡等判定 |
| 生物质小圆片 | 红 15 枚 + 蓝 15 枚 | 用于计数[[生物质]] |
| [[墙壁]] | 若干 | 癌细胞建造的屏障 |
| [[卡池]] | 3 组 | 免疫卡池、癌症卡池、世界事件卡池 |

## 三组卡池

- **免疫卡池**：[[免疫卡牌]] 抽卡来源，供免疫细胞玩家抽取。
- **癌症卡池**：[[癌症卡牌]] 抽卡来源，供癌细胞玩家抽取。
- **世界事件卡池**：触发[[世界事件]] 时随机抽取。

> 特殊事件地块由免疫细胞玩家在设置阶段摆放位置，见 [[游戏设置]]。
