# 游戏设置（开局流程）

开局前依次完成以下 4 步：

1. **摆放特殊事件**：免疫细胞玩家决定各[[特殊事件地块]] 的位置。所有[[卡池]] 初始为 **未激活** 状态（激活规则见 [[游戏阶段]]）。
2. **确定癌组织**：癌细胞玩家选择 **7 块** [[组织]] 作为**癌组织**，其余 **54 块** 为**正常组织**。
   - 癌组织**不能**与特殊事件地块重合，也**不能位于其周围**（相邻）。
3. **选择初始位置**：玩家按[[玩家行动顺序]] 依次选择初始位置。
   - 癌细胞只能选**癌组织**作为初始位置；
   - 免疫细胞只能选**正常组织**作为初始位置。
4. **分配生物质**：每位玩家拥有 **5 点[[生物质]]**，生物质上限为 **5**。

## 开局要点

- 癌组织仅 7 块，免疫细胞阵营开局占优（54 块正常组织），而癌细胞通过[[感染]] 扩张。
- 卡池初始未激活 → 只有到达**激活**状态才可抽卡（见 [[玩家回合-判定阶段]]）。
