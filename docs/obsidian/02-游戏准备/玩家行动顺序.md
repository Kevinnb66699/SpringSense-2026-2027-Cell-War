# 玩家行动顺序

玩家按固定顺序轮流行动。一个[[世界回合]] 内，所有人按此顺序各行动一次。

## 4 名玩家

```
免疫细胞 A → 癌细胞 A → 免疫细胞 B → 癌细胞 B
```

## 6 名玩家

```
免疫细胞 A → 癌细胞 A → 癌细胞 B → 免疫细胞 B → 免疫细胞 C → 癌细胞 C
```

> 注意：6 人局中前两位癌细胞先行动（癌 A、癌 B），随后才是免疫 B、免疫 C。

## 行动顺序的用途

- [[游戏设置]]：按此顺序选择初始位置。
- [[进化]]（第 10 回合）：按此顺序选择能力。
- 世界事件 [[突袭]]：所有细胞按行动顺序依次移动 3 步。
