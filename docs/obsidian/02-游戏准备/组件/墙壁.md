# 墙壁

墙壁是癌细胞建造的防御性屏障。

## 功能

- 墙壁**阻挡免疫细胞的移动和攻击**，但对**癌细胞不产生影响**。
- 获得途径：
  - [[墙壁工厂]]：回合开始获得 2 枚（可被[[地狱制造]] / [[Heavy worker]] 加成）；
  - 癌细胞特殊行动 [[建造]]：在周围任意数量建造。
- 拆除：免疫细胞特殊行动 [[拆除]] 可拆除与当前组织相邻的一面墙壁，以及与其连通的**所有墙壁**。

## 与事件/能力的互动

- [[洪水]]：本回合所有墙壁无效。
- [[大洪水]]：棋盘上所有墙壁消失。
- [[纤维化]]：所有癌细胞可选择当前组织的一面生成墙壁。
- 进化能力 [[中性粒细胞]]：无视墙壁。
