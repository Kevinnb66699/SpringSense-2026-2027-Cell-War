# 墙壁工厂

墙壁工厂是让癌细胞获得[[墙壁]] 的特殊事件地块，共 **1 个**。

## 功能

- **回合开始判定**：位于墙壁工厂的癌细胞获得 **2 枚墙壁**（[[玩家回合-判定阶段]]）。
- 世界事件 [[地狱制造]]（[[限定词条|限定]]）：本回合在墙壁工厂获得的墙壁数量 **+1**（即 3 枚）。
- 能力卡牌 [[Heavy worker]]：从墙壁工厂获得的墙壁数量 +1。
