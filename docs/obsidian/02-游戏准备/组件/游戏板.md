# 游戏板

- 游戏板是游戏的棋盘本体，由 **61 块[[组织]]** 构成。
- 特殊事件（[[特殊事件地块]]）在开局时由免疫细胞玩家摆放于棋盘上，见 [[游戏设置]]。

## 棋盘上的元素

- 61 块[[组织]]：正常组织 / 普通癌组织 / 固化癌组织。
- [[特殊事件地块]]：卡池、血管、生物质工厂、墙壁工厂。
- [[墙壁]]：可被癌细胞建造在组织上，阻挡免疫细胞。
