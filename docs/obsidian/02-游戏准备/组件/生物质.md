# 生物质

**生物质**是玩家的核心资源（生命 + 能量）。

## 基础规则

- 每位玩家开局拥有 **5 点生物质**，**上限 5**（[[游戏设置]]）。
- 用红/蓝小圆片计数（15 红 + 15 蓝）。

## 生物质的消耗与获得

| 动作 | 消耗 / 获得 |
|------|------------|
| 受到攻击（大成功） | 失去 X 点生物质（X = 攻击力） |
| [[燃烧抽卡]]（自由抽卡） | 消耗 2 点生物质 |
| [[突变抽卡]]（癌细胞） | 消耗 1 点生物质 + 掷骰 |
| [[复活]]（固化癌组织 / 事件） | 以 1 点生物质复活 |
| [[生物质工厂]] | 回合结束回复 1 点 |
| 卡牌（Glucose/Maltose 等） | +1 / +2 点 |
| 世界事件 | 获得 / 失去 / 降为 1 点等 |

## 相关机制

- 生物质为 0 → 细胞**死亡**；死亡可通过复活重回棋盘（[[玩家回合-判定阶段]]、[[世界事件]]）。
- [[巨噬细胞]] 能力：对癌细胞造成的伤害回复为自己的生物质。
- 部分[[世界事件]]（如[[生死关头]]）将全体生物质降为 1。
