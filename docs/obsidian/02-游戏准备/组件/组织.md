# 组织（棋盘地块）

棋盘由 **61 块组织** 构成，是细胞所在的位置单位。组织分为三种状态：

## 组织状态

| 状态 | 说明 | 产生方式 |
|------|------|---------|
| **正常组织** | 免疫细胞阵营的地盘基础 | 初始 54 块；[[净化]] 可把癌组织转回正常组织 |
| **普通癌组织** | 癌细胞的地盘 | 初始 7 块；[[感染]] 把正常组织变为癌组织；是[[净化]] 与[[固化]] 的目标 |
| **固化癌组织** | 不可被净化的癌组织 | [[固化]] 计数达 3 时由普通癌组织转变；[[死亡细胞复活]] 的基地 |

## 关键规则

- 开局：癌细胞选 **7 块** 为癌组织，其余 **54 块** 为正常组织（[[游戏设置]]）。
- [[感染]]：正常组织 → 普通癌组织（癌细胞特殊行动）。
- [[净化]]：普通癌组织 → 正常组织（免疫细胞特殊行动，也见于部分[[免疫事件]]/卡牌）。
- [[固化]]：普通癌组织 → 固化癌组织（需固化计数到 3）。
- **固化癌组织无法被净化**。
- 癌组织是癌细胞[[死亡细胞复活|复活]] 的场所，复活详见 [[玩家回合-判定阶段]]。
