# 血管

血管是棋盘上的**传送点**特殊事件地块，共 **2 个**。

## 功能

- **回合开始判定**：位于血管的细胞在回合开始时**传送**到另一处血管（[[玩家回合-判定阶段]]）。
- 卡牌 [[VEGF]] 可将一个血管移动 1-3 步（不能与其他特殊事件重合）。
- 进化能力 [[血液癌]]：移动过程中遇到血管立即传送。

## 规则细节

- 2 个血管互为传送目标：站上其中一个 → 回合开始被送到另一个。
