# 骰子

游戏中配备 **2 个骰子**，用于各类随机判定。

## 主要用途

| 场景 | 规则 |
|------|------|
| [[移动]] | 掷 1 骰：1-3 移动 1 步；4-5 移动 2 步；6 移动 3 步 |
| [[攻击]] | 掷 1 骰判定[[攻击结果]]：1 失败；2-3 成功；4-6 大成功 |
| [[卡池]] 抽卡资格 | 不同阵营玩家在同一激活卡池时掷骰，点数大者抽卡 |
| [[突变抽卡]] | 1-3 无事发生；4-6 抽一张卡 |

## 相关事件/能力

- [[战斗狂潮]]：本回合攻击必定大成功（跳过掷骰）。
- [[自然杀伤细胞]]：攻击必然大成功。
- [[Precise recognition]]：下一次攻击一定成功。
