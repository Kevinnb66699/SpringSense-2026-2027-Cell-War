# 世界回合

**世界回合**是游戏的最高优先级判定单位。

## 定义

- 每一轮（**世界回合**）= 所有玩家分别进行一个 [[玩家回合]]。
- 一局游戏共有 **20 个世界回合**。

## 流程位置

```
世界回合开始
 ├─ （若达到激活节点）卡池激活 + 触发世界事件 → 见 [[游戏阶段]]
 ├─ 每位玩家依次执行玩家回合 → 见 [[玩家回合]]
 └─ 世界回合结束
```

## 相关节点

- 卡池激活与[[世界事件]] 触发节奏由[[游戏阶段]] 决定。
- 第 10 回合开始时发生[[进化]]。
- 所有世界回合结束（或提前满足条件）后判定[[胜负条件|胜负]]。
