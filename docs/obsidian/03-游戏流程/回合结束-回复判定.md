# 回合结束-回复判定

玩家的行动结束之后，进行回复判定：

- 位于**[[生物质工厂]]** 的细胞在回合结束时回复 **1 点[[生物质]]**。
- 世界事件 [[天堂制造]]（[[限定词条|限定]]）可使该回复量 **+1**。

> 这是玩家回合的最后一步，之后轮到下一位玩家（[[玩家行动顺序]]）。
