# 复活（死亡与复活机制）

## 死亡

- 细胞[[生物质]] 为 0 即死亡。癌细胞全部死亡且无法复活 → 免疫细胞立即胜利（[[胜负条件]]）。

## 复活方式

### 1. 普通复活（回合开始判定 1）

- 若棋盘上有**固化癌组织**，死亡的癌细胞可选择在该组织上以 **1 点生物质**复活（[[玩家回合-判定阶段]]）。
- 随后该固化癌组织变为**普通癌组织**。
- 复活后的癌细胞**本回合可以行动**。
- 相关：[[固化]]。

### 2. 能力复活（癌症干细胞）

- 进化能力 [[癌症干细胞]]：死亡后下一个自己的回合，可消耗其他癌细胞 1 点生物质，在任意癌组织上以 1 点生物质复活。

### 3. 世界事件复活

| 事件 | 效果 |
|------|------|
| [[医学奇迹]] | 死亡免疫细胞全部以 1 点生物质在任意正常组织复活（该回合无法行动） |
| [[死灰复燃]] | 死亡癌细胞全部以 1 点生物质在任意癌组织复活（该回合无法行动） |
| [[二次机会]] | 死亡的所有细胞全部以 1 点生物质在任意己方阵营组织复活（该回合无法行动） |

> 事件复活后该世界回合内无法采取行动（区别于普通复活的"可行动"）。
