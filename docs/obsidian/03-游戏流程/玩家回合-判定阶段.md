# 玩家回合-判定阶段

玩家的回合开始，依次进行如下判定：

## 判定 1：复活

- 若棋盘上有**固化癌组织**，死亡的癌细胞可选择在该组织上以 **1 点生物质**复活。
- 随后该固化癌组织变为**普通癌组织**。
- 复活后的癌细胞**本回合可以行动**。
- 相关：[[固化]]、[[癌症干细胞]]、[[死亡细胞复活]]。

## 判定 2：血管

- 位于[[血管]] 的细胞在回合开始时**传送**到另一处[[血管]]。

## 判定 3：抽卡（卡池）

- 位于**激活卡池**的玩家可以从**对应阵营的卡池**抽一张卡。
- 若**不同阵营**玩家位于同一激活卡池 → 掷[[骰子]] 决定，**点数大者**获得抽卡资格；同阵营玩家则**商议确定**。
- 随后该卡池从**激活**变为**未激活**。
- 相关：[[卡池]]、[[游戏阶段]]（激活节奏）。

## 判定 4：墙壁

- 位于[[墙壁工厂]] 的癌细胞获得 **2 枚[[墙壁]]**（可被[[地狱制造]] / [[Heavy worker]] 加成）。

> 判定按 复活 → 血管 → 抽卡 → 墙壁 的顺序依次结算。
