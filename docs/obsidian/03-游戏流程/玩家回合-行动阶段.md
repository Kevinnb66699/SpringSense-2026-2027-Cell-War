# 玩家回合-行动阶段

判定结束后，玩家可以依次采取以下行动：

## 行动 1：自由抽卡

- 详见 [[自由抽卡]]（燃烧抽卡 / 突变抽卡），抽卡次数无限制。

## 行动 2：移动与攻击

- 掷[[骰子]] 移动（[[移动]]）；免疫细胞移动结束后若目标在其攻击范围内则触发[[攻击]]。
- 攻击结果（失败/成功/大成功）、[[击退]]、[[眩晕]]、[[双重打击]] 详见对应笔记。

## 行动 3：特殊行动

- 每回合**仅能选择一种**特殊行动，详见 [[特殊行动]]。

> 顺序固定：自由抽卡 → 移动与攻击 → 特殊行动。
