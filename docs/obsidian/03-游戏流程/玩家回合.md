# 玩家回合

一名玩家的回合包含三个依次进行的部分：

```
玩家回合开始
 ├─ 1. [[玩家回合-判定阶段]]
 │      判定1 复活 → 判定2 血管 → 判定3 抽卡 → 判定4 墙壁
 ├─ 2. [[玩家回合-行动阶段]]
 │      行动1 自由抽卡 → 行动2 移动与攻击 → 行动3 特殊行动
 └─ 3. [[回合结束-回复判定]]
        生物质工厂回复
```

## 阶段说明

- **判定阶段**：回合开始时的被动结算（复活、血管传送、卡池抽卡、墙壁工厂）。
- **行动阶段**：玩家主动操作（自由抽卡、移动与攻击、特殊行动）。
- **回复判定**：回合结束时的资源回复。

## 特殊状态

- [[眩晕]]：被击退出界的癌细胞跳过**下一回合**（本回合不能行动）。
- 世界事件影响：如[[二次机会]]、[[休养生息]] 等会改变本回合行动能力。
