# 攻击力

- **攻击力 X** 决定 [[攻击]] 大成功时：
  - 癌细胞失去的[[生物质]] 点数（伤害）；
  - 若癌细胞存活，被[[击退]] 的步数。
- 默认攻击力为 **1**（手册默认无加成时）。

## 攻击力加成来源

| 来源 | 类型 | 加成 |
|------|------|------|
| [[T细胞]] | 进化能力 | 攻击力 +1 |
| [[记忆T细胞]] | 进化能力 | 每次击杀癌细胞后攻击力 +1 |
| [[Cell-mediated immunity]] | 卡牌（能力） | 攻击力 +1 |
| [[Cytokine]] | 卡牌（即时） | 下一次攻击攻击力 +1 |
| [[炎症风暴]] | 世界事件 | 本回合所有免疫细胞攻击力 +1 |
| [[免疫暴走]] | 世界事件 | 本回合生物质>1 的免疫细胞攻击力 +1（大成功后失去 1 点生物质） |

## 相关

- 减伤手段会抵消攻击力伤害：[[实体癌]]（-1）、[[Keratinization]]（免疫下一次伤害）。
