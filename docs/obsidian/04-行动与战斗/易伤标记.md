# 易伤标记

## 来源

- 由进化能力 **[[树突状细胞]]** 添加：其移动阶段对进入[[攻击范围]] 的癌细胞添加一个易伤标记。

## 效果

- 具有易伤标记的癌细胞受到的攻击**必然成功**（跳过[[攻击结果]] 的失败可能）；
- 受到的伤害 **+1**。
- 易伤标记**不可累计**（同一目标最多一个）。
