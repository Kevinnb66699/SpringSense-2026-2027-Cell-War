# 拆除（免疫细胞特殊行动）

- 效果：拆除**与当前组织相邻的一面墙壁**，同时拆除**与该墙壁连通的所有墙壁**。
- 免疫细胞每回合可选择净化或拆除（见 [[特殊行动]]）。

## 规则细节

- "连通"指与目标墙壁相连成片的所有墙壁会被一并拆除（连锁清除）。
- 应对癌细胞用[[建造]] 筑起的[[墙壁]] 防线。
