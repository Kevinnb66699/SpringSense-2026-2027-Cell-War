# 移动（行动 2 前半）

## 基础规则

- 掷一次[[骰子]] 进行移动：

| 骰子点数 | 移动步数 |
|----------|---------|
| 1 - 3 | 1 步 |
| 4 - 5 | 2 步 |
| 6 | 3 步 |

- 移动的过程中**可以改变移动方向**。

## 修改移动距离/方式的来源

| 来源 | 效果 |
|------|------|
| [[血液癌]]（进化） | 移动距离始终 +1；移动中遇[[血管]] 立即传送 |
| [[转移癌]]（进化） | 失去特殊行动能力，每回合**固定移动 1 步**，自动感染接触组织 |
| [[免疫巡逻]]（事件） | 本回合所有免疫细胞行动距离 +1 |
| [[癌症渗透]]（事件） | 本回合所有癌细胞行动距离 +1 |
| [[突袭]]（事件） | 所有细胞按[[玩家行动顺序]] 依次移动 3 步 |
| [[Chemotaxis]] / [[Metastasis]]（卡牌·能力） | 每回合移动阶段开始前可移动 1 步 |
| [[Information detection]] / [[Infiltration]]（卡牌） | 本回合获得 1 次额外移动机会 |

## 墙壁的影响

- 墙壁阻挡免疫细胞移动（[[中性粒细胞]] 可无视），见 [[墙壁]]。
