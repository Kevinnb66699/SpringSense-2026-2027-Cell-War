# 树突状细胞（免疫细胞进化能力）

## 效果

- **失去攻击能力**。
- **移动阶段**对进入攻击范围的癌细胞添加一个 **[[易伤标记]]**。
  - 易伤标记**不可累计**；
  - 具有易伤标记的癌细胞受到的攻击**必然成功**，并且受到的伤害 **+1**。

## 定位

- 辅助型：自身不输出，但为队友创造必中 + 增伤窗口。
