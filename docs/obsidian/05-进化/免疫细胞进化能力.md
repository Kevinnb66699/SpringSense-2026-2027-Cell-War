# 免疫细胞进化能力

第 10 回合[[进化]] 时，免疫细胞玩家可从以下 **8 项**中选择一项（不可重复选择）：

| 能力 | 效果 | 笔记 |
|------|------|------|
| B细胞 | 攻击距离 +1 | [[B细胞]] |
| T细胞 | 攻击力 +1 | [[T细胞]] |
| 记忆B细胞 | 每次击杀癌细胞后攻击距离 +1 | [[记忆B细胞]] |
| 记忆T细胞 | 每次击杀癌细胞后攻击力 +1 | [[记忆T细胞]] |
| 自然杀伤细胞 | 攻击必然大成功 | [[自然杀伤细胞]] |
| 巨噬细胞 | 对癌细胞造成的伤害回复为自己的生物质 | [[巨噬细胞]] |
| 中性粒细胞 | 无视墙壁 | [[中性粒细胞]] |
| 树突状细胞 | 失去攻击能力；移动阶段对进入攻击范围的癌细胞添加[[易伤标记]] | [[树突状细胞]] |
