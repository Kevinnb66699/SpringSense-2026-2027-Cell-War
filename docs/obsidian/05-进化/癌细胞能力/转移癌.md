# 转移癌（癌细胞进化能力）

## 效果

- **失去特殊行动能力**（不可[[感染]]/[[固化]]/[[建造]]）。
- 每回合**固定移动 1 步**（不掷骰）。
- **自动感染**你接触到的组织（接触即 [[感染]]）。

## 定位

- 渗透型：牺牲灵活与特殊行动，换取稳定的"边移动边扩张癌组织"。
