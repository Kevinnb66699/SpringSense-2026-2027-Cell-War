# 世界事件

世界事件是随[[游戏阶段]] 触发节奏、从**世界事件卡池**随机抽取的全局效果。

## 触发时机

- 前期：第 **3、6、9** 回合（每 3 个世界回合）。
- 后期：**偶数回合**（每 2 个世界回合）。
- 触发同时，棋盘上所有[[卡池]] 变为激活。

## 分类

- [[免疫事件]]：对免疫细胞阵营有利。
- [[癌事件]]：对癌细胞阵营有利。
- [[共同事件]]：对双方均有影响。

## 特殊词条

- 含 **[[限定词条|限定]]** 的事件在一局游戏中只能触发一次。

- 癌症：[[癌事件]]（9 项）
