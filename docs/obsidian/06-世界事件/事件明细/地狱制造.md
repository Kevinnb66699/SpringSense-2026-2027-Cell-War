# 地狱制造（癌事件 · 限定）

- 效果：在[[墙壁工厂]] 获得的[[墙壁]] 数量 **+1**（即本回合 3 枚）。
- **含[[限定词条]]**：一局游戏中只能触发一次。

## 相关

- 与能力卡 [[Heavy worker]] 效果相同。
