# 免疫事件（对免疫细胞有利）

| 事件 | 效果 |
|------|------|
| 医学奇迹 | 死亡的免疫细胞全部以 1 点[[生物质]] 在任意**正常组织**复活，该世界回合内无法采取行动 |
| 精准医疗 | 免疫细胞阵营任意选择一名癌细胞，将其生物质**降为 1** |
| 放疗 | 所有免疫细胞可分别选择失去 1 点生物质，[[净化]] 棋盘上任一普通癌组织 |
| 战斗狂潮 | 本世界回合触发的攻击必定**大成功** |
| 洪水 | 本世界回合内所有[[墙壁]] **无效** |
| 大洪水 | 棋盘上**所有墙壁消失** |
| 免疫强化 | 所有免疫细胞**抽一张卡** |
| 炎症风暴 | 本世界回合内所有免疫细胞攻击力 **+1** |
| 免疫暴走 | 本世界回合内所有生物质大于 1 的免疫细胞攻击力 +1，攻击大成功之后**失去 1 点生物质** |
| 免疫巡逻 | 本世界回合所有免疫细胞**行动距离 +1** |

## 相关机制

- 复活类：[[医学奇迹]] → [[玩家回合-判定阶段]] 复活。
- 攻击类：战斗狂潮 → [[攻击结果]]；炎症风暴/免疫暴走 → [[攻击力]]。
- 墙壁类：洪水/大洪水 → [[墙壁]]。
- 净化类：放疗 → [[净化]]。
