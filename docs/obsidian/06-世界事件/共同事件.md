# 共同事件（对双方均有影响）

| 事件 | 效果 |
|------|------|
| 二次机会 | 死亡的所有细胞全部以 1 点[[生物质]] 在任意**己方阵营**的组织复活，该回合内无法采取行动 |
| 天降甘霖 | 所有细胞获得 1 点生物质 |
| 化疗 | 所有生物质大于 1 的细胞失去 1 点生物质 |
| 生死关头 | 所有细胞的生物质**降为 1** |
| 天堂制造（限定） | [[生物质工厂]] 的回复量 **+1** |
| 突袭 | 所有细胞按[[玩家行动顺序]] 依次**移动 3 步** |
| 衰弱 | 双方阵营分别选择对方阵营其中一名角色具有的**其中一张能力牌**消除 |
| 休养生息 | 本回合可以选择**放弃移动和特殊行动**，分别可以回复 1 点生物质 |

> 标"（限定）"为含[[限定词条]] 的事件，一局仅触发一次。

## 相关机制

- 生物质增减：天降甘霖、化疗、生死关头 → [[生物质]]。
- 复活：二次机会 → [[玩家回合-判定阶段]]。
- 移动：突袭 → [[移动]]。
- 能力牌消除：衰弱 → [[卡牌类型|能力卡牌]]。
- 回复：休养生息、天堂制造 → [[生物质工厂]]。
