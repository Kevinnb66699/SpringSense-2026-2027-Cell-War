# 癌事件（对癌细胞有利）

| 事件 | 效果 |
|------|------|
| 死灰复燃 | 死亡的癌细胞全部以 1 点生物质在任意**癌组织**复活，该世界回合内无法采取行动 |
| 医疗事故 | 癌细胞阵营任意选择一名免疫细胞，将其生物质**降为 1** |
| 恶化 | 所有癌细胞可选择当前组织或周围的组织**其中一枚进行感染** |
| 地狱制造（限定） | 在[[墙壁工厂]] 获得的墙壁数量 **+1** |
| 纤维化 | 所有癌细胞可选择当前组织的一面**生成墙壁** |
| 转移 | 所有癌细胞可分别选择失去 1 点生物质，**感染**棋盘上任一正常组织 |
| 癌症强化 | 所有癌细胞**抽一张卡** |
| 免疫逃逸 | 本世界回合**癌细胞不会受到攻击** |
| 癌症渗透 | 本世界回合所有癌细胞**行动距离 +1** |

> 标"（限定）"为含[[限定词条]] 的事件，一局仅触发一次。

## 相关机制

- 感染类：恶化、转移 → [[感染]]。
- 墙壁类：地狱制造、纤维化 → [[墙壁]] / [[墙壁工厂]]。
- 免疫：免疫逃逸 → [[攻击]]。
