# 限定词条

- 含有 **「限定」** 词条的事件在一局游戏中**只能触发一次**。
- 触发后该事件不再重复出现。

## 含"限定"的事件

- 癌事件：[[癌事件|地狱制造]]（墙壁工厂产出墙壁 +1）
- 共同事件：[[共同事件|天堂制造]]（生物质工厂回复量 +1）
