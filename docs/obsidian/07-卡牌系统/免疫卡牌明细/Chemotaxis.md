# Chemotaxis（趋化性）

- 类型：**[[卡牌类型|能力]]**（置于角色面板，永久生效）
- 数量：1 张（免疫卡池）
- 效果：**每回合的移动阶段开始前可以移动 1 步**。

## 相关

- 癌细胞对应能力卡：[[Metastasis]]。
- 可与 [[移动]] 的基础移动叠加。
