# VEGF（血管内皮生长因子）

- 类型：**[[卡牌类型|即时]]**
- 数量：1 张（免疫卡池）+ 1 张（癌症卡池）
- 效果：将一**[[血管]] 移动 1-3 步**，不能和其他特殊事件重合。

## 用途

- 改变棋盘上传送点的位置，影响 [[玩家回合-判定阶段]] 的血管传送。
