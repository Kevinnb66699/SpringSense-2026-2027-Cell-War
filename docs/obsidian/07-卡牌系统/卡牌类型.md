# 卡牌类型（即时 / 能力）

卡牌分为两种类型：

## 即时（Instant）

- **抽到此卡时即时生效**，一次性效果。
- 例：移动 3 步、生物质 +1、传送、抽两张卡等。

## 能力（Ability）

- **抽到此卡时置于角色面板上**，**永久生效**（持续到游戏结束或被消除）。
- 例：攻击范围 +1、攻击力 +1、每回合移动前先走 1 步等。

## 能力牌的消除

- 世界事件 [[共同事件|衰弱]]：双方阵营分别选择对方阵营其中一名角色具有的**其中一张能力牌消除**。

## 能力牌一览

- 免疫：[[Chemotaxis]]、[[Humoral immunity]]、[[Cell-mediated immunity]]
- 癌症：[[Metastasis]]、[[Heavy worker]]、[[Doom]]
