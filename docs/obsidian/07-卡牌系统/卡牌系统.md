# 卡牌系统

卡牌是游戏的主要变数来源，分阵营存在。**卡牌表可以自由设计拓展包**。

## 获取途径

- [[玩家回合-判定阶段]]：位于**激活卡池**抽卡。
- [[自由抽卡]]：燃烧 2 点生物质 / 癌细胞突变抽卡。
- 部分[[世界事件]]（免疫强化、癌症强化）与进化效果。

## 卡牌类型

- 卡牌分为两种类型：**[[卡牌类型|即时 / 能力]]**。
  - **即时**：抽到此卡时**即时生效**。
  - **能力**：抽到此卡时**置于角色面板上永久生效**。

## 阵营卡表

- [[免疫卡牌]]（免疫细胞专用，18 张）
- [[癌症卡牌]]（癌细胞专用，18 张）

## 规则要点

- 卡牌分阵营：免疫细胞从[[免疫卡牌|免疫卡池]] 抽，癌细胞从[[癌症卡牌|癌症卡池]] 抽。
- 事件 [[衰弱]] 可消除对方角色的一张能力牌。
