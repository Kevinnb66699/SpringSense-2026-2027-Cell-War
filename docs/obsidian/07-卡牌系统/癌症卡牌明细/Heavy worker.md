# Heavy worker（重工）

- 类型：**[[卡牌类型|能力]]**（永久生效）
- 数量：1 张（癌症卡池）
- 效果：从[[墙壁工厂]] 获得的[[墙壁]] 数量 **+1**（即每回合 3 枚）。

## 相关

- 与事件 [[癌事件|地狱制造]] 效果相同（均为墙壁工厂产出 +1）。
