# Metastasis（转移灶）

- 类型：**[[卡牌类型|能力]]**（永久生效）
- 数量：1 张（癌症卡池）
- 效果：**每回合的移动阶段开始前可以移动 1 步**。

## 相关

- 免疫细胞对应能力卡：[[Chemotaxis]]。
- 与进化 [[转移癌]] 名称相近但机制不同：本卡不牺牲特殊行动。
