# Cell War 手册 · Obsidian 笔记库说明

本目录（`docs/obsidian/`）将《Cell War（ver.0.98）》桌游手册（`docs/游戏手册 ver.0.98.pdf`）拆分为**细粒度（原子化）**的 Obsidian 笔记，便于知识检索、双向链接与二次加工。

## 如何使用

1. 在 Obsidian 中：**打开文件夹作为仓库（Open folder as vault）**，选择本目录 `docs/obsidian/`。
2. 从 **[[游戏手册-总览]]**（MOC 总览页）开始浏览。
3. 笔记之间通过 **双向链接** 相互引用；使用左侧"反向链接/图谱"视图查看关系网。

## 约定

- 每篇笔记带 **YAML frontmatter**：`title`、`tags`（`cellwar/...` 层级标签）、`source`（出处页码）。
- 每篇笔记文末附 **相关笔记**（反向链接）。
- 卡牌/事件原文以表格 + 原子笔记两种粒度呈现。
- 英文卡牌名保留原文标题，便于与手册对应。
