# 规则电子化说明（对应游戏手册 ver.0.98）

本文档记录电子版对规则的实现方式，**特别是手册中有歧义、电子化时必须做出解释的地方**。
如果团队对某条解释有不同意见，改动通常只涉及 `game/scripts/core/` 中的少量代码，欢迎提 issue 讨论。

## 代码结构

| 文件 | 职责 |
|---|---|
| `core/hexlib.gd` | 六边形坐标数学（轴向坐标、距离、边/角、像素换算） |
| `core/cw_data.gd` | 静态数据：常量、官方地图布局、卡牌表、世界事件表、进化表 |
| `core/cw_board.gd` | 棋盘状态：组织类型、固化计数、特殊事件、墙壁（含连通判定） |
| `core/cw_player.gd` | 玩家状态：生物质、进化、能力牌、各类标记 |
| `core/cw_deck.gd` | 卡池：抽牌堆+弃牌堆，抽空洗回 |
| `core/cw_game.gd` | 游戏流程状态机：布置、20 世界回合、判定、攻击、卡牌、世界事件、胜负 |
| `core/cw_bridge.gd` | 问答桥：引擎需要玩家决策时 `await bridge.ask()`，由 UI 或 AI 应答 |
| `ui/` | 界面层：棋盘绘制（`board_view.gd`）、主控制器（`main.gd`）、真人桥/演示桥 |
| `tests/headless_test.gd` | 无头自动测试：随机策略跑完整局并校验不变量 |

规则逻辑完全不依赖界面，便于将来做联机或 AI。

## 基础设定（已确认）

- **棋盘**：61 块组织 = 半径 4 的六边形蜂窝（每行 5-6-7-8-9-8-7-6-5），与官方比赛地图一致。
- **官方地图特殊事件布局**（从比赛地图读出，中心对称，轴向坐标）：
  卡池 (3,-4) (-3,-1) (3,1) (-3,4)；血管 (-4,0) (4,0)；生物质工厂 (0,-3)；墙壁工厂 (0,3)。
  布置阶段免疫阵营可一键采用官方布局，也可自定义放置。
- **墙壁**位于六边形组织的边上；只能建在两块组织之间的边（棋盘外缘的边无阻挡意义，不可建）。
- 生物质上限 5；生物质降为 0 即死亡。
- 攻击力基础值 1，攻击范围基础值 0（手册只给了范围初始值，攻击力基础 1 由"大成功失去 X 点生物质"倒推）。

## 规则解释决策（歧义处）

编号即代码中的实现，供对照手册校对：

1. **"X 点以上"按严格大于实现**：燃烧抽卡需生物质 ≥3（燃烧 2 点后至少剩 1），突变抽卡需 ≥2，放疗/转移事件的付费需 ≥2，干细胞复活的队友需 ≥2。理由：手册在 Evolution/Mutation 卡与免疫暴走中明确写"大于 1"，可见设计意图是**主动消耗不会让细胞死亡**；此实现与该意图一致。
2. **移动可以少走**：掷骰后可走 0 至掷出步数，随时"结束移动"。手册未明说是否必须走满；电子版取宽松解释。
3. **攻击触发**：免疫细胞每次"移动结束"后强制触发（含额外移动机会、Diapedesis、突袭事件的移动）；卡牌传送/换位（Teleporting/Translocation）不算移动，不触发攻击。范围内有多个癌细胞时攻击方选择一个目标，每次移动结束只攻击一次。
4. **击退方向**：沿免疫细胞最后一步的移动方向；若本回合未移动过（0 步结束），由攻击方选择方向。攻击失败的后退为最后移动方向的反方向。
5. **攻击范围与墙壁**：免疫细胞的攻击范围按"考虑墙壁的绕行步数"计算（BFS），中性粒细胞与洪水回合按直线距离。范围 0（同格）不受墙壁影响。
6. **免疫细胞后退受阻**（墙壁或棋盘边缘）则原地不动，不眩晕——手册的【眩晕】只定义在癌细胞被击退出界的情形。
7. **大成功的净化**：手册中"若该癌细胞在被攻击时位于普通癌组织上，则净化该癌组织"位于大成功段落内，故仅大成功时净化（击杀同样净化）；净化的是被攻击时所站的那一格。
8. **击退步数 X = 攻击力**：易伤的伤害 +1 与实体癌的伤害 -1 只影响伤害，不影响击退步数（手册明确 X 等同于攻击力）。
9. **易伤标记**：不可叠加；受到一次攻击后消耗（该次攻击必然成功且伤害 +1）。
10. **双重打击**可链式发生；"其他免疫细胞"= 本次造成击退的攻击者以外的免疫细胞；树突状细胞无攻击能力，不参与双重打击。方向不变，因此链条必然在边缘（眩晕）前终止。
11. **卡池争夺**：不同阵营同处激活卡池时，该格所有玩家各掷一骰，最高者获得抽卡资格（平局者重掷）；若只有同阵营多人，由当前回合玩家指定队内一人抽卡（"商议"的电子化）。
12. **Excalibur**：手册原文"净化一条直线上的所有**癌细胞**"，但"净化"在手册中只定义于组织，且其对位卡 Nuclear radiation 也是组织效果；电子版实现为**净化经过自身的一整条直线（双向）上的所有普通癌组织**。若确认原意是消灭癌细胞，改 `cw_game.gd` 的 `excalibur` 分支即可。
13. **Doom【能力】**：按"永久生效"实现为——持有者每个自己回合结束时，自动感染当前组织及周围一圈。此卡强度极高，若实测过强建议改为【即时】一次性效果（改动一行）。
14. **转移癌**：固定移动 1 步（不掷骰、不吃行动距离加成），移动进入的组织自动感染；失去特殊行动；"额外移动机会"对其等于再走固定 1 步。
15. **血液癌**："移动距离始终 +1"应用于掷骰移动与卡牌移动（Diapedesis 类）；移动途中进入血管立即传送到另一端并继续行走。
16. **进化**：第 10 世界回合开始时全部玩家（含已死亡者）按行动顺序选择，同阵营内不可重复；癌细胞任意方式复活后可更换为一个未被同阵营选择的能力。
17. **"死亡且无法复活"的立即胜利判定**：所有癌细胞死亡，且场上无固化癌组织（判定 1 复活无门），且干细胞复活无存活队友可消耗——则免疫立即获胜。世界事件的随机复活不计入"可复活"预测。
18. **特殊行动的作用对象为当前所在组织**（净化/感染/固化）；建造/拆除针对当前组织相邻的边。恶化事件是明确写了"当前或周围"的扩大版。
19. **特殊事件格的本体是正常组织**：可以被感染（不影响特殊事件功能继续存在）；初始 7 块癌组织不能选在特殊事件及其周围（手册规定）。
20. **"己方阵营的组织"**：免疫细胞 = 正常组织；癌细胞 = 癌组织（含固化）。用于 Teleporting 与二次机会复活。
21. **Good day** 只能转换普通癌组织（固化癌组织不可被净化的规则优先）。
22. **休养生息**：该回合结束时，未移动 +1 生物质、未使用特殊行动 +1 生物质。
23. **世界事件**均匀随机抽取、可重复出现，【限定】事件触发一次后移出池——与原 `world_event.py` 行为一致。卡池在事件回合全部激活。
24. **非自己回合抽到"额外移动机会"卡**（如通过免疫强化事件）无效果。
25. **树突状细胞**的标记发生在其自己的移动阶段：每走一步及移动结束时，对进入其攻击范围的癌细胞添加易伤。
26. **拆除**：选择相邻的一面墙后，与其**共享角点**连通的整片墙壁一并拆除。
27. **固化计数衰减**在每个世界回合开始时结算：计数 >0 且无癌细胞站立的组织计数 -1。
28. **Keratinization** 原文不完整（"免疫下一次攻击受到的生物质伤害"），按"下一次受到攻击时生物质伤害无效"实现（击退照常）。
29. **衰弱事件**顺序：免疫阵营先选，癌症阵营后选；被消除的能力牌进入对应卡池弃牌堆。
30. **抽卡即时结算**：即时卡抽到立刻生效（需要选目标的会提示当事玩家操作）；能力卡立即置于面板永久生效。

## 电子版形态

- v1 为**本地热座**：同一台电脑，所有信息公开（本游戏卡牌即抽即用，无手牌隐藏需求），按行动顺序轮流操作。
- **人机对战**（`ui/hybrid_bridge.gd`）：人类执一个阵营，AI 执另一阵营。AI 为启发式策略：
  免疫细胞追击最近的癌细胞（无目标时去净化癌组织）、优先净化/拆墙；癌细胞在免疫细胞
  3 格内时逃跑（路线倾向踩正常组织边逃边感染）、被逼近时优先筑墙、安全时朝最近正常组织
  扩散感染；进化偏好免疫 NK/T 细胞、癌症血液癌/实体癌；攻击目标选生物质最低者。
  AI 强度为 v1 水平，平衡细调依赖真人试玩反馈。
- 主菜单提供**随机演示模式**：全部决策由随机 AI 完成，用于快速观战与冒烟测试。

## 测试

```
cd game
godot --headless --import                      # 首次运行：生成 .godot 缓存（class_name 注册）
godot --headless -s tests/headless_test.gd
```

仓库配有 GitHub Actions（`.github/workflows/tests.yml`）：每次 push 自动下载 Godot 并跑无头测试。

- 校验六边形库（61 格、距离、边/角连通、官方布局合法性）；
- 用 4 个随机种子跑完整局（4 人与 6 人各两局），校验：布置合法、生物质 0–5、位置在棋盘内、墙壁边合法、组织总数恒为 61、必有胜负。
